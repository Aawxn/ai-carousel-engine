# Just Sortd — Creative AI Carousels (PRD 4)

> **Goal:** Turns approved text takes into on-brand 5-slide visual carousels in under 15 minutes of human time, featuring designer-owned templates, pre-render copy-fit validation, and surgical 1-slide re-rendering (`dirty_slides`).  
> 📄 **Core Documents:** [1-Page Build Plan](BUILD_PLAN.md) | [Ops Runbook](RUNBOOK.md) | [Loom Script](LOOM_SCRIPT_PRD4_AI_CAROUSELS.md)

---

### 1. File Flow
* **`brand_tokens.json` & `templates/slide_template.html`:** Graphic designer owns typography, colors (`#0D1117`, `#6366F1`), and 1080×1350 4:5 aspect ratio rules; operates as a headless rendering engine.
* **`carousel_contract.json`:** Structured 5-slide JSON generated by AI with strict slot budgets.
* **`renderer.py`:** Runs deterministic pre-render Copy-Fit validation (Headline ≤ 60, Body ≤ 100), and checks `dirty_slides` so editing Slide 3 skips Slides 1, 2, 4, 5.
* **`rendered_output/` & Handoff:** Produces 1080×1350 PNG slides (previewable in `carousel_viewer.html`) and exports directly into PRD 2's `handoff_contract.json`.

---

### 2. Run Locally
```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run renderer (Full render or surgical 1-slide edit)
python renderer.py
python renderer.py --dirty-only

# 3. Run test suite
python -m pytest tests/
```

---

### 3. Integration Status
* **Headless Chromium / Playwright:** Renders crisp 1080×1350 PNG slides locally in <100ms without SaaS fees (100% free alternative to Canva/Bannerbear).
* **Notion Review & PRD 2 Handoff:** Review happens inside the native Notion Content gallery; approved carousels export directly into PRD 2 (`handoff_contract.json`) with zero custom frontend.
